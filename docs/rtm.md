# RTM

## Бизнес-цели

| ID | Бизнес-цель |
| --- | --- |
| BG-01 | Дать читателю возможность вести единый цифровой читательский дневник и отслеживать чтение |
| BG-02 | Дать возможность обсуждать книги асинхронно, без необходимости синхронной встречи |
| BG-03 | Сделать обсуждение безопасным с точки зрения спойлеров за счёт привязки тредов к прогрессу чтения |

| BG-06 | Монетизировать расширенные возможности продукта через Premium |
