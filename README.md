# PageMates

PageMates — мобильное приложение для тех, кто любит читать и обсуждать книги. Оно помогает вести читательский дневник, отслеживать прогресс, сохранять заметки и цитаты, а также обсуждать прочитанное с другими читателями с защитой от спойлеров.

## Реализованный функционал
- Экран профиля: информация о себе (аватар, имя пользователя, описание), список добавленных книг
- Экран книги: название, автор, обложка, статус, количество прочитанных страниц, тэги, заметки, цитаты
- Экран добавления новой книги: название, автор, обложка, статус, количество страниц, тэги, заметки, цитаты
